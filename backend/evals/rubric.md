# LLM-judged eval rubric (future harness)

## Voice consistency
Does the resume read as one person wrote it? Score **1–5** (5 = fully consistent tone and diction).

## Keyword coverage
Fraction of must-have keywords from the JD present in the tailored output. Score **0.0–1.0**.

## Hallucination
Any metric, employer, or technology not supported by source bricks? **pass** / **fail**.

## Length
Correct page count for the target (typically one page)? **pass** / **fail**.

## Fluency
No dangling punctuation; bullets are complete phrases. **pass** / **fail**.
